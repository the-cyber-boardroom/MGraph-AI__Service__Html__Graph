# LLM Brief: Entity Listing API

**version**: v1.4.60

## Overview

This document describes the new Entity Listing API endpoint that enables discovery and browsing of cached entities within a namespace.

---

## 1. Why We Built This

### The Problem

The FLeT HTML caching system stores HTML content and associated data in "entities" - each identified by a `cache_id` and associated with a `cache_key` (like `site/example.com/pages/home`). 

Previously, consumers had no way to answer: **"What entities exist in my namespace?"**

Without this capability:
- UI applications couldn't display a list of cached content
- Users couldn't browse what was stored
- Discovery required knowing the exact `cache_id` or `cache_key` in advance

### Design Considerations

We considered several approaches:

1. **Path-based browsing** - Let users browse the raw storage structure
   - ❌ Rejected: Breaks the entity abstraction, creates security concerns, loses the concept of `cache_id`

2. **Central index** - Maintain a separate index of all entities
   - ❌ Rejected: Adds complexity, synchronization issues, storage overhead

3. **On-demand entity enumeration** - List all `cache_id`s, load metadata for each
   - ✅ Chosen: Maintains entity abstraction, uses existing infrastructure, secure

### The Solution

A new endpoint that:
1. Retrieves all `cache_id`s in a namespace (via existing cache service)
2. Loads metadata for each entity (cache_key, timestamp, strategy, etc.)
3. Optionally includes the list of data files per entity
4. Returns a structured response suitable for UI rendering

## 2. How It Works

### Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                         API Request                              │
│         GET /cache-entity/{namespace}/entities                   │
│                    ?include_data_files=true                      │
└─────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Cache__Entity__Service                        │
│                      list_entities()                             │
└─────────────────────────────────────────────────────────────────┘
                                │
                ┌───────────────┴───────────────┐
                ▼                               ▼
┌───────────────────────────┐   ┌───────────────────────────────┐
│   cache_client.namespace()│   │      Cache__Entity            │
│      .cache_ids()         │   │   .entry__with_metadata()     │
│                           │   │   .data__files()              │
│   Returns: List of all    │   │                               │
│   cache_ids in namespace  │   │   Returns: Metadata + files   │
└───────────────────────────┘   └───────────────────────────────┘
                │                               │
                └───────────────┬───────────────┘
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│                 Schema__Entity__List__Response                   │
│  {                                                               │
│    success: true,                                                │
│    namespace: "html-cache",                                      │
│    count: 3,                                                     │
│    entities: [Schema__Entity__Info, ...]                         │
│  }                                                               │
└─────────────────────────────────────────────────────────────────┘
```

### Data Flow

1. **Get all cache_ids**: `cache_client.namespace().cache_ids(namespace)` returns all entity IDs
2. **For each cache_id**: Create a `Cache__Entity` bound client
3. **Load metadata**: Call `entity.entry__with_metadata()` which hits `/{namespace}/retrieve/{cache_id}`
4. **Optionally load files**: Call `entity.data__files(recursive=True)` which hits `/{namespace}/cache/{cache_id}/data/list`
5. **Build response**: Aggregate into `Schema__Entity__List__Response`

## 3. What It Does

### Endpoint

```
GET /cache-entity/{namespace}/entities
GET /cache-entity/{namespace}/entities?include_data_files=true
```

### Response Schema

#### Schema__Entity__List__Response

| Field     | Type                     | Description                    |
|-----------|--------------------------|--------------------------------|
| success   | bool                     | Always `true` on success       |
| namespace | Safe_Str__Cache__Namespace | The queried namespace        |
| count     | int                      | Number of entities found       |
| entities  | list[Schema__Entity__Info] | List of entity information   |

#### Schema__Entity__Info

| Field            | Type                           | Description                        |
|------------------|--------------------------------|------------------------------------|
| cache_id         | Cache_Id                       | Unique entity identifier           |
| cache_key        | Safe_Str__Cache__File__Cache_Key | Semantic key (e.g., site/example.com) |
| cache_hash       | Safe_Str__Cache_Hash           | Content hash                       |
| file_id          | Safe_Str__Cache__File__File_Id | File identifier (usually "root")   |
| namespace        | Safe_Str__Cache__Namespace     | Namespace                          |
| strategy         | Enum__Cache__Store__Strategy   | Storage strategy (e.g., "key_based") |
| stored_at        | Timestamp_Now                  | Unix timestamp when created        |
| file_type        | Enum__Cache__Data_Type         | Data type (e.g., "json")           |
| content_encoding | Safe_Str__Id                   | Encoding (e.g., "gzip") or null    |
| content_size     | Safe_UInt                      | Size in bytes                      |
| data_files       | list[dict] or null             | Data files (only if requested)     |

#### Data File Structure (when include_data_files=true)

Each item in `data_files` contains:

| Field        | Type   | Description                              |
|--------------|--------|------------------------------------------|
| data_file_id | string | File identifier (e.g., "raw")            |
| data_key     | string | Data key path (e.g., "html", "flows/html-to-cache") |
| data_type    | string | Type: "string" or "json"                 |
| file_path    | string | Full storage path                        |
| file_size    | int    | Size in bytes                            |
| extension    | string | File extension (e.g., "txt", "json")     |

### Key UI Considerations

1. **Loading State**: Entity listing requires N+1 calls (1 for cache_ids, N for metadata). Show loading indicator.

2. **Pagination**: For large namespaces, consider client-side pagination. Future: server-side pagination.

3. **Sorting**: Response is unsorted. Client should allow sorting by:
   - `cache_key` (alphabetical)
   - `stored_at` (newest/oldest)
   - `content_size` (largest/smallest)

4. **Filtering**: Client can filter by:
   - `cache_key` prefix (e.g., "site/")
   - `strategy` type
   - Date range

5. **Data Files Toggle**: Use `include_data_files=false` for list view (faster), `true` for detail view.

### Example Web Component Structure

```javascript
// entity-list.js
class EntityList extends HTMLElement {
    constructor() {
        super();
        this.entities = [];
        this.loading = true;
    }

    static get observedAttributes() {
        return ['namespace'];
    }

    get namespace() {
        return this.getAttribute('namespace');
    }

    connectedCallback() {
        this.render();
        this.loadEntities();
    }

    attributeChangedCallback(name, oldValue, newValue) {
        if (name === 'namespace' && oldValue !== newValue) {
            this.loadEntities();
        }
    }

    async loadEntities() {
        this.loading = true;
        this.render();

        try {
            const response = await fetch(`/cache-entity/${this.namespace}/entities`);
            const data = await response.json();
            this.entities = data.entities;
        } catch (error) {
            console.error('Failed to load entities:', error);
            this.entities = [];
        }

        this.loading = false;
        this.render();
    }

    handleRowClick(entity) {
        this.dispatchEvent(new CustomEvent('entity-selected', {
            detail: { entity },
            bubbles: true
        }));
    }

    render() {
        if (this.loading) {
            this.innerHTML = `<div class="loading">Loading entities...</div>`;
            return;
        }

        this.innerHTML = `
            <h1>Entities in ${this.namespace}</h1>
            <table class="entity-table">
                <thead>
                    <tr>
                        <th>Cache Key</th>
                        <th>Stored At</th>
                        <th>Strategy</th>
                    </tr>
                </thead>
                <tbody>
                    ${this.entities.map(entity => `
                        <tr data-cache-id="${entity.cache_id}">
                            <td>${entity.cache_key}</td>
                            <td>${new Date(entity.stored_at).toLocaleString()}</td>
                            <td>${entity.strategy}</td>
                        </tr>
                    `).join('')}
                </tbody>
            </table>
        `;

        this.querySelectorAll('tbody tr').forEach(row => {
            row.addEventListener('click', () => {
                const cacheId = row.dataset.cacheId;
                const entity = this.entities.find(e => e.cache_id === cacheId);
                this.handleRowClick(entity);
            });
        });
    }
}

customElements.define('entity-list', EntityList);

// entity-detail.js
class EntityDetail extends HTMLElement {
    constructor() {
        super();
        this.entity = null;
    }

    static get observedAttributes() {
        return ['namespace', 'cache-id'];
    }

    get namespace() { return this.getAttribute('namespace'); }
    get cacheId()   { return this.getAttribute('cache-id'); }

    connectedCallback() {
        this.render();
        this.loadEntity();
    }

    attributeChangedCallback(name, oldValue, newValue) {
        if (oldValue !== newValue) {
            this.loadEntity();
        }
    }

    async loadEntity() {
        if (!this.namespace || !this.cacheId) return;

        try {
            const response = await fetch(
                `/cache-entity/${this.namespace}/entities?include_data_files=true`
            );
            const data = await response.json();
            this.entity = data.entities.find(e => e.cache_id === this.cacheId);
        } catch (error) {
            console.error('Failed to load entity:', error);
            this.entity = null;
        }

        this.render();
    }

    render() {
        if (!this.entity) {
            this.innerHTML = `<div class="loading">Loading entity...</div>`;
            return;
        }

        const { cache_id, cache_key, cache_hash, stored_at, data_files } = this.entity;

        this.innerHTML = `
            <div class="entity-detail">
                <h2>${cache_key}</h2>
                <dl>
                    <dt>Cache ID</dt>
                    <dd>${cache_id}</dd>
                    <dt>Cache Hash</dt>
                    <dd>${cache_hash}</dd>
                    <dt>Stored</dt>
                    <dd>${new Date(stored_at).toLocaleString()}</dd>
                </dl>
                
                <h3>Data Files</h3>
                <ul class="data-files">
                    ${(data_files || []).map(file => `
                        <li data-key="${file.data_key}" data-file-id="${file.data_file_id}">
                            ${file.data_key}/${file.data_file_id} 
                            <span class="file-meta">(${file.file_size} bytes, ${file.data_type})</span>
                        </li>
                    `).join('')}
                </ul>
            </div>
        `;

        this.querySelectorAll('.data-files li').forEach(li => {
            li.addEventListener('click', () => {
                this.dispatchEvent(new CustomEvent('file-selected', {
                    detail: {
                        dataKey: li.dataset.key,
                        fileId: li.dataset.fileId,
                        cacheId: this.cacheId,
                        namespace: this.namespace
                    },
                    bubbles: true
                }));
            });
        });
    }
}

customElements.define('entity-detail', EntityDetail);
```

## 6. Related Endpoints

Once you have the entity list, these endpoints are useful for further operations:

| Action | Endpoint | Method |
|--------|----------|--------|
| Get entity metadata | `/cache-entity/{ns}/entity/{cache_id}/metadata` | GET |
| Check entity exists | `/cache-entity/{ns}/entity/{cache_id}/exists` | GET |
| Delete entity | `/cache-entity/{ns}/entity/{cache_id}` | DELETE |
| Get string data file | `/cache-data/{ns}/data/{cache_id}/string/{data_key}/{file_id}` | GET |
| Get JSON data file | `/cache-data/{ns}/data/{cache_id}/json/{data_key}/{file_id}` | GET |
| List FLeT flows | `/flet-flows/flows/{ns}/{cache_id}` | GET |
| Get flow logs | `/flet-flows/flows/{ns}/{cache_id}/{flet_name}/logs` | GET |

## 7. Performance Notes

### Current Implementation

- **N+1 calls**: One call per entity to fetch metadata
- **Suitable for**: Small to medium namespaces (< 100 entities)
- **Data files**: Additional call per entity when `include_data_files=true`

### Future Optimizations

1. **Batch API**: Fetch multiple entity metadata in one call
2. **Server-side pagination**: `?limit=20&offset=0`
3. **Caching**: Cache entity metadata on client side
4. **Streaming**: Stream large entity lists

### Recommendations

- For UI list views: Use `include_data_files=false` (default)
- For detail views: Fetch data files on demand
- For large namespaces: Implement client-side pagination/virtualization
