# Phase A: Source Node Tracking

**Status**: 🚧 Ready to Start  
**Depends On**: Html_Use_Case__3 (4-step flatten transformation) ✅

---

## Objective

> Track which original nodes contribute to each merged/consolidated node, enabling reverse operations from flattened graph back to original HTML.

---

## The Problem

Currently, when we flatten HTML like:

```html
<div>This is a <a href="#">link</a> with some <b>bold</b> text</div>
```

We get a merged text node:
```
"This is a link with some bold text"
```

But we **lose track** of which original nodes created this:
- Text node: "This is a "
- `<a>` element with text "link"
- Text node: " with some "
- `<b>` element with text "bold"
- Text node: " text"

**Without this tracking, we cannot:**
- Delete the merged text and have it remove the original nodes
- Highlight the merged text and have it add classes to original elements
- Map classifications back to source HTML

---

## Solution Design

### Step A.1: Create Source Tracking Schema

Add a way to store source node references on merged nodes.

**Option 1: Extend node_data**
```python
# In merged node's node_data
node_data = {
    'value'           : 'This is a link with some bold text',
    'value_type'      : str,
    'source_node_ids' : ['node_001', 'node_002', 'node_003', 'node_004', 'node_005']
}
```

**Option 2: Dedicated edge type**
```
merged_node ─[source_of]─► original_text_1
merged_node ─[source_of]─► original_a_tag
merged_node ─[source_of]─► original_b_tag
...
```

**Recommendation**: Option 2 (edges) - keeps relationships in the graph, enables graph queries.

### Step A.4: Preserve Original Nodes (Important Decision)

**Current behavior**: Original text nodes are deleted after merging.

**Options**:

| Option | Pros | Cons |
|--------|------|------|
| A. Delete originals | Clean graph, less memory | Cannot trace back |
| B. Keep originals, mark as "merged" | Full traceability | Larger graph |
| C. Keep originals in separate subgraph | Clean main graph + traceability | More complex |

**Recommendation**: Option C - Store original nodes in a "source_nodes" subgraph or mark them with a flag so they're hidden from normal traversal but available for reverse mapping.

### Step A.5: Query API for Source Nodes

```python
class Html_Use_Case__3(Graph_Transformation__Base):
    
    def get_source_nodes(self, merged_node_id: Node_Id) -> List[Node_Id]:
        """Get original node IDs that were merged into this node."""
        index = self.result_mgraph.index()
        source_edges = index.get_node_outgoing_edges_by_predicate(
            merged_node_id, 
            predicate='source_of'
        )
        return [index.edges_index.get_edge_to_node(e) for e in source_edges]
    
    def get_merged_node(self, original_node_id: Node_Id) -> Optional[Node_Id]:
        """Get the merged node that contains this original node."""
        index = self.result_mgraph.index()
        incoming = index.get_node_incoming_edges_by_predicate(
            original_node_id,
            predicate='source_of'
        )
        if incoming:
            return index.edges_index.get_edge_from_node(next(iter(incoming)))
        return None
```

## Test Cases

### Test A.1: Simple Text Merge Tracking

```python
def test_source_tracking__simple_merge():
    html = '<p>Hello <b>world</b>!</p>'
    
    # Process through flatten
    flat_graph = transform(html)
    
    # Find merged node
    merged = get_merged_text_nodes(flat_graph)[0]
    assert merged.value == 'Hello world!'
    
    # Get sources
    sources = flat_graph.get_source_nodes(merged.node_id)
    assert len(sources) == 3  # "Hello ", <b>→"world", "!"
```

### Test A.2: Reverse Lookup

```python
def test_source_tracking__reverse_lookup():
    html = '<div>Click <a>here</a> now</div>'
    
    # Get original node IDs before transform
    original_graph = parse(html)
    text_node_ids = [n.node_id for n in original_graph.text_nodes()]
    
    # Transform
    flat_graph = transform(html)
    
    # Each original should map to the same merged node
    merged_ids = set()
    for orig_id in text_node_ids:
        merged = flat_graph.get_merged_node(orig_id)
        merged_ids.add(merged)
    
    assert len(merged_ids) == 1  # All map to same merged node
```

### Test A.3: Complex Structure
