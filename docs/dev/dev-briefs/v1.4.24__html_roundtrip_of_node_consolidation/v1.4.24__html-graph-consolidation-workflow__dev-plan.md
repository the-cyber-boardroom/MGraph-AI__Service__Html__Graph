## Executive Summary

This workflow transforms a web page into a simplified, navigable graph representation that:
1. Consolidates inline formatting (`<a>`, `<b>`, `<i>`, etc.) into merged text nodes
2. Collapses single-parent chains for cleaner visualization
3. **Maintains bidirectional mapping** between merged nodes and source Node_Ids
4. Enables operations on merged nodes that propagate back to original HTML

---

## Key Architecture Decision: Node_Ids at Html_Dict Level

**The insight**: Node_Ids should be created at the `Html_Dict` level, not inside `Html_MGraph__Document`. This enables:
- Transformations directly on `Html_Dict` using Node_Ids (faster, no MGraph needed)
- Source tracking that works across the entire pipeline
- Optional MGraph creation only when graph queries are needed


## Phase A: Html_Dict Node_Id Assignment

**Objective**: Create `Html__To__Html_Dict__With__Node_Ids` that adds unique `node_id` to every element and text node during parsing.

### Implementation

```python
class Html__To__Html_Dict__With__Node_Ids(Html__To__Html_Dict):
    
    def handle_starttag(self, tag, attrs):
        super().handle_starttag(tag, attrs)
        # Add node_id to the new tag (via self.current or last appended)
        
    def handle_data(self, data):
        super().handle_data(data)
        # Add node_id to text node if created
        
    def generate_node_id(self) -> str:
        return str(Obj_Id())
```

### Output Format

```python
# Before (Html__To__Html_Dict):
{'tag': 'div', 'attrs': {}, 'nodes': [
    {'type': 'TEXT', 'data': 'Hello'}
]}

# After (Html__To__Html_Dict__With__Node_Ids):
{'tag': 'div', 'attrs': {}, 'nodes': [
    {'type': 'TEXT', 'data': 'Hello', 'node_id': 'abc123'}
], 'node_id': 'def456'}
```

### Deliverables
1. `Html__To__Html_Dict__With__Node_Ids` class

## Phase C: Source Tracking in Transformations

**Objective**: Track source node_ids in `Html_Use_Case__3` transformations so we can trace merged nodes back to originals.

### Implementation

```python
class Html_Use_Case__3(Graph_Transformation__Base):
    
    source_mapping : Dict[str, List[str]] = {}         # merged_node_id → [source_node_ids]
    wrapper_mapping: Dict[str, Dict]      = {}         # wrapper_node_id → {parent, child info}
    
    def step_3___merge_text_nodes(self, mgraph):
        # Before creating merged node, collect source_node_ids
        source_node_ids = [child['node_id'] for child in text_children]
        
        # Create merged node
        merged_node = self.create_merged_text_node(...)
        
        # Track mapping
        self.source_mapping[merged_node_id] = source_node_ids
    
    def get_source_node_ids(self, merged_node_id: str) -> List[str]:
        return self.source_mapping.get(merged_node_id, [])
```

### Workflow with Source Tracking

```python
# 1. Parse with node_ids
html_dict = Html__To__Html_Dict__With__Node_Ids(html).convert()

# 2. Convert to MGraph (node_ids preserved)
doc = Html__To__Html_MGraph__Document().convert_from_dict(html_dict)

# 3. Transform with tracking
transformer = Html_Use_Case__3()
flat_graph = transformer.transform_mgraph(doc.body_graph.copy())

# 4. Get source nodes for any merged node
merged_node_id = "some_merged_id"
source_ids = transformer.get_source_node_ids(merged_node_id)

# 5. Delete from original dict using source_ids
for source_id in source_ids:
    remove_node_from_dict(html_dict, source_id)

# 6. Export to HTML
html = Html_Dict__To__Html(html_dict).convert()
```
